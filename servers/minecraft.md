CoderDojo 京都四条 では、ニンジャ・保護者・メンターが一緒に遊べる **Minecraft サーバー** を運営しています。Dojo の時間の外でも、仲間とつくる・遊ぶ体験の場としてご活用ください。

## 接続情報

| 項目 | 内容 |
|------|------|
| エディション | 統合版（Bedrock Edition） |
| サーバーアドレス | `153.127.218.145` |
| ポート番号 | `19132` |

> **対応プラットフォーム：** Windows 10/11・Xbox・PlayStation・Nintendo Switch・iOS・Android など、統合版が動作するすべての機器から接続できます。Java Edition（PC 版）には対応していません。

## 事前準備：Microsoft アカウントでのログイン

このサーバーへの接続には **Microsoft アカウントへのログインが必須** です。アカウントをお持ちでない方は、接続前に作成・ログインしてください。

Microsoft アカウントが必要な理由は2つあります。第一に、誰でも接続できる状態にするとサーバーへの負荷が高くなりすぎたり、見知らぬ人による荒らし行為が起きる恐れがあります。第二に、このサーバーは **Dojo に参加してくれた方だけ**が利用できる場所にしたいと考えているため、事前登録制を採用しています。Microsoft アカウントのゲーマータグをもとに参加者を管理しています。

> **13歳未満のお子さんの場合：** 保護者の Microsoft アカウントで「Microsoft ファミリー」を設定し、子どもアカウントを作成する必要があります。

### Microsoft アカウントの作成

1. [Microsoft アカウント作成ページ](https://account.microsoft.com/) にアクセス
2. 「アカウントを作成」からメールアドレスを登録
3. 13歳未満の場合は、保護者のアカウントで [Microsoft ファミリー](https://account.microsoft.com/family/) から子どもアカウントを追加

### Minecraft へのログイン

| プラットフォーム | ログイン方法 |
|---|---|
| iOS / Android | アプリ起動時にサインイン画面が表示されます |
| Nintendo Switch | 本体の「設定」→「ユーザー」→「Nintendo アカウント」経由でリンク後、Minecraft 起動時にサインイン |
| Windows 10/11 | Minecraft（統合版）起動時に Microsoft アカウントでサインイン |

ログイン後、Minecraft のプロフィールにゲーマータグ（表示名）が設定されます。このゲーマータグをサーバー参加申請の際に Discord でお知らせください。

## 接続方法

### スマートフォン・タブレット（iOS / Android）

1. Minecraft を起動し、「プレイ」をタップ
2. 「サーバー」タブを選択
3. 画面下の「サーバーを追加」をタップ
4. サーバー名（例：`CoderDojo 京都四条`）、アドレス・ポートを入力して「保存」

### Nintendo Switch

1. Minecraft を起動し、「プレイ」→「サーバー」タブを選択
2. 一覧の一番下にスクロールし、「その他のサーバーを追加」を選択
3. サーバー名・アドレス・ポートを入力して確定

### Windows 10/11

1. Minecraft（統合版）を起動し、「プレイ」→「サーバー」タブを選択
2. 「サーバーを追加」をクリック
3. サーバー名・アドレス・ポートを入力して「保存」
